# RVKino Distribution — статический сайт

## Состав
- `index.html` — структура сайта.
- `style.css` — адаптивная монохромная стилизация.
- `script.js` — каталог, модальные окна и локальная админ-панель.
- `assets/posters/` — постеры фильмов.
- `assets/team/` — фотографии команды.
- `assets/logo/` — логотип.

## Медиафайлы
Создайте/используйте папки `assets/posters`, `assets/team`, `assets/logo`.

Положите логотип `logo.png` в `assets/logo/`.
Постеры (имена должны совпадать точно):
- `po_sledam_schastya.jpg`
- `krazha_bez_pravil.jpg`
- `gran_vybora.jpg`
- `taissya_kalinina.jpg`
- `ne_moy_golos.jpg`
- `veshhestva_v_efire.jpg`

Фотографии команды:
- `vlad.jpg`
- `diana.jpg`

Если изображение отсутствует или путь неверный, появится нейтральная серая заглушка.

## Запуск локально
Откройте `index.html` в браузере. Для корректной работы iframe-трейлеров и тестирования можно запустить локальный сервер, например расширением Live Server в VS Code.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `rvkino-distribution`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js` и папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве ветки выберите `main`, папку `/ (root)`, затем нажмите **Save**.
6. Подождите завершения публикации. GitHub покажет адрес сайта вида `https://ВАШ-ЛОГИН.github.io/rvkino-distribution/`.

## Как пользоваться админ-панелью
Внизу сайта нажмите `Admin Panel`. Пароль по умолчанию: `admin`.
В панели можно добавлять, редактировать и удалять фильмы, а также менять email, телефон и ссылки Дианы.

**Важное ограничение:** это демонстрационная админка без сервера. Пароль находится в JavaScript, а данные сохраняются в LocalStorage конкретного браузера. Поэтому изменения видны только в том браузере и на том устройстве, где их внесли. Посетители сайта не получают эти изменения, а любой технически подготовленный человек может обойти такую защиту. Не храните здесь конфиденциальные данные и не используйте этот механизм для реального управления публичным сайтом. Для общей админки с авторизацией и синхронизацией нужен backend или CMS.

## Замена пароля
В `script.js` найдите `const ADMIN_PASSWORD = "admin";` и измените значение. Это не превращает клиентскую админку в безопасную систему.
