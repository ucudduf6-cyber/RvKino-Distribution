# RVKINO DISTRIBUTION — статический сайт Проект готов для GitHub Pages: HTML, CSS и JavaScript, без сборки и серверной части. ## Дизайн и сведения о фильмах Обновлённая визуальная система: тёмная кинематографичная шапка и hero-блок, контрастная типографика с антиквенным акцентом, спокойная тёплая палитра, крупная сетка постеров, аккуратные линии и адаптивная навигация. Данные в карточках фильмов приведены по доступным карточкам Кинопоиска; сведения, которые не удалось достоверно получить из карточек, намеренно не добавлены. ## Перед публикацией обязательно 1. Добавьте четыре официальных постера в `images/` с именами `po-sledam-schastya.jpg`, `taisiya-kalinina.jpg`, `gran-vybora.jpg`, `krazha-bez-pravil.jpg`. 2. Замените блоки `.poster-placeholder` на `` с указанными путями. В `films/*.html` путь начинается с `../images/`, в `index.html` — с `images/`. Используйте `object-fit:contain`. 3. Проверьте даты, сведения о фильмах и внешние ссылки непосредственно перед запуском. 4. Заполните юридические документы в `legal/`: реквизиты исполнителя, цели и сроки обработки персональных данных, способы оплаты и возврата. Квадратные поля — незаполненные места, не вымышленные реквизиты. 5. Утвердите тарифы и состав каждого пакета. До оплаты письменно фиксируйте стоимость работы по каждой площадке. ## Формы заявок GitHub Pages не имеет собственного сервера для приёма заявок. Формы проверяют обязательные поля и открывают почтовую программу через `mailto:` с письмом на `RvKinoproduction@zohomail.com`. Пользователь должен самостоятельно подтвердить отправку. Если нужна автоматическая доставка без почтовой программы, подключите внешний сервис форм и endpoint, затем замените обработчик в `js/main.js`. ## Публикация Загрузите содержимое проекта в корень репозитория GitHub. Затем откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Сохраните настройки. ## Состав Главная, четыре страницы фильмов, услуги и цены, актёрам, кинотеатральный прокат, о компании, контакты, правовые страницы, CSS, JS и папка для оригинальных постеров. ## Ограничения Сайт не гарантирует принятие фильмов сторонними площадками, выдачу прокатного удостоверения или кинотеатральные сеансы. Публикация зависит от решений соответствующих организаций. ## Постеры и логотипы В `images/` добавлены четыре оригинальных постера, предоставленных заказчиком. Они используются в каталоге и на индивидуальных страницах фильмов. Иконки Telegram и ВКонтакте подключены как SVG-логотипы Simple Icons CDN; ссылки ведут на указанные в проекте аккаунты RVKINO Distribution. Для загрузки иконок требуется подключение к интернету.
